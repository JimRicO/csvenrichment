
# Club Intelligence Enrichment Module

A comprehensive enrichment system that combines website scraping (via Firecrawl) and Instagram analysis (via Apify) to build rich club profiles with brand identity, contact data, and personality insights.

## AI Model

**Claude Sonnet 4.5** (`claude-sonnet-4-5`) via Anthropic API — consistent with the existing project-qa function and using the already-configured `ANTHROPIC_API_KEY`.

---

## Overview

This module accepts a **Club Name**, **Website URL**, and **Instagram Handle** as inputs, then orchestrates multiple data sources to produce a unified enrichment profile containing:

- Logo (persisted to storage)
- Instagram handle + profile data
- Business address
- Color palette & fonts (via Firecrawl branding)
- Club description
- Club "attitude" (brand voice/personality)
- Club "aesthetics" (visual style analysis)

The attitude and aesthetics will be generated by Claude Sonnet 4.5 by combining website content analysis with Instagram visual analysis.

## Edge Functions

### 1. create-enrichment-job

Creates a new enrichment job from user input.

**Input modes:**
- Single club: `{ club_name, website_url, instagram_handle }`
- Bulk CSV: `{ rows: [{ club_name, website_url, instagram_handle }, ...] }`

**Process:**
1. Generate job ID (ENRICH_timestamp_random)
2. Insert into enrichment_jobs
3. Insert rows into enrichment_rows
4. Return job_id for monitoring

### 2. enrichment-worker

The main orchestrator that processes one pending row at a time.

**Process per row:**
1. Lock row (set status = processing)
2. **Website Scrape** (Firecrawl):
   - Call Firecrawl scrape API with `formats: ['markdown']`
   - Collect markdown content from homepage
3. **Branding Extraction** (Firecrawl):
   - Call Firecrawl with `formats: ['branding']`
   - Download and persist logo to `brand-images` storage bucket
   - Extract colors, fonts, typography
4. **Instagram Scrape** (Apify):
   - Call Apify instagram-profile-scraper
   - Persist profile picture to `instagram-profile-pics` bucket
   - Extract bio, followers, recent post captions
5. **AI Analysis** (Claude Sonnet 4.5):
   - Combine website content + Instagram data
   - Generate description (from website content)
   - Analyze attitude (brand voice from website copy + Instagram captions)
   - Analyze aesthetics (visual style from colors + Instagram themes)
6. **Store Results** in enriched_clubs
7. Update job progress via increment function

### 3. get-enrichment-status

Returns job status and row-level progress (similar to existing get-job-status).

### 4. download-enrichment-csv

Exports enriched data as CSV for download.

BRANDING:
- Color scheme: {color_scheme}

Generate the following in JSON format:

1. DESCRIPTION (2-3 sentences):
A concise description of what this club offers and who it serves.

2. ATTITUDE (2-3 sentences):
The brand's personality and voice. Consider tone, values, communication style, and positioning.

3. AESTHETICS (2-3 sentences):
Their visual style. Consider color mood, design style, and overall visual impression.

Return JSON:
{
  "description": "...",
  "attitude": "...",
  "aesthetics": "..."
}

## Cost Estimation

Per club enrichment:
- Firecrawl scrape: ~$0.001 (1 credit)
- Firecrawl branding: ~$0.001 (1 credit)
- Apify Instagram: ~$0.003
- Claude Sonnet 4.5: ~$0.003 (estimated ~1K input + 500 output tokens)
- **Total: ~$0.008 per club**
